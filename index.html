Configuration Firebase requise

L'app a besoin d'un projet Firebase pour synchroniser tes relevés entre les téléphones.

  1. Crée un projet sur console.firebase.google.com
  2. Active Firestore Database (région europe)
  3. Ajoute une app Web et copie l'objet de config
  4. Colle les 6 clés dans index.html — bloc CONFIG FIREBASE
Tant que la config n'est pas remplie, seule cette page s'affiche.
